# AI-Assisted Development Reflection

## 1. What did you ask AI to help you build? How did you break down the problem?

For this assignment, I decided to build a Stock Portfolio Tracker because I am interested in investing and wanted to create something that I could actually use. The goal was to create a website where users could add stocks, enter the number of shares they own, and calculate their investment profits or losses.

I originally planned to use GitHub Copilot, but I had trouble getting it to work in Visual Studio Code. Because of that, I switched to ChatGPT to help me develop the application.

I broke the project down into three main parts. First, I created the HTML structure. Next, I added CSS to make the website look more professional. Finally, I used JavaScript to make the application interactive and calculate investment performance.

## 2. How did your approach to asking questions change as you worked?

At the beginning, I focused on getting the basic application created. I wanted to understand which files were needed and how they worked together.

As I progressed, I realized that breaking the development process into smaller steps made it easier to follow. Instead of trying to build everything at once, I worked through the HTML, CSS, and JavaScript separately.

This approach made the instructions easier to understand and helped me identify what each part of the code was responsible for.

## 3. What parts of the development process with AI surprised you?

One thing that surprised me was how quickly ChatGPT could generate a working application. I expected the process to be more complicated, especially when it came to calculating investment profits and losses.

I also found it interesting that the application could save stock information even after refreshing the browser. I did not realize that JavaScript could store information locally without requiring a database.

Overall, the experience showed me how AI can make software development more efficient while still requiring the developer to understand and test the code.

## 4. What did you learn about the technology you used that you didn't know before?

I learned more about how HTML, CSS, and JavaScript work together to create an interactive website. HTML provides the structure, CSS controls the appearance, and JavaScript handles the functionality.

One concept I learned about was localStorage, which allows a website to save information in the browser. This was useful because I wanted users to be able to refresh the page without losing their portfolio information.

I also learned how JavaScript can take user inputs, perform calculations, and automatically update information displayed on a webpage.

## 5. What would you do differently if you had to build this again?

If I were to complete this project again, I would spend more time planning the features before starting development. I would also try to troubleshoot GitHub Copilot earlier so I could gain experience using it directly in Visual Studio Code.

Another improvement would be adding live stock prices through an API instead of requiring users to enter prices manually. I would also consider adding charts to make the portfolio easier to understand.

Overall, this project helped me see how AI can assist with software development. I learned that being able to explain what you want, follow instructions, and test the results is just as important as generating the code.
