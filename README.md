# Stock-Portfolio-Tracker

## Project Description

The Stock Portfolio Tracker is a simple web application that allows users to manage their stock investments and monitor their portfolio performance. Users can enter stock information, calculate investment values, and view their profits or losses.

This project was developed using HTML, CSS, and JavaScript with assistance from ChatGPT.

## Features

- Add stocks using ticker symbols.
- Enter the number of shares and purchase price.
- Enter current stock prices.
- Automatically calculate total investment and portfolio value.
- Display profits and losses.
- Remove stocks from the portfolio.
- Save stock information using browser localStorage.

## Technologies Used

- **HTML:** Creates the structure of the application.
- **CSS:** Styles the application with a dark-themed interface.
- **JavaScript:** Handles user interactions, calculations, and data storage.
- **ChatGPT:** Assisted with code generation, explanations, and project development.

## Installation Instructions

1. Clone the GitHub repository:

   `git clone https://github.com/Jetlife105/Stock-Portfolio-Tracker.git`

2. Open the project folder in Visual Studio Code.
3. Locate the `index.html` file.
4. Open `index.html` in a web browser.

No additional software packages or dependencies are required.

## How to Use

1. Open the Stock Portfolio Tracker.
2. Enter a stock ticker symbol, such as NVDA.
3. Enter the number of shares owned.
4. Enter the original purchase price per share.
5. Enter the current stock price per share.
6. Click **Add Stock**.
7. Review your total investment, current portfolio value, and profit or loss.
8. Click **Remove** to delete a stock.

The application stores portfolio information locally in the browser. Current stock prices must be entered manually.
